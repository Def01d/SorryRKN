# Изменения

## 1.0.0

- Новое приложение `io.github.def01d.sorryrkn` с постоянным ключом подписи. Последующие APK сохраняют пакет и сертификат.
- Отдельный подписанный канал `android-update.json`, проверка при запуске и проверка пакета до скачивания.
- Сохранение настроек, Telegram-секрета и AndroidKeyStore-хранилища при обновлении проверяется на настоящих производственных APK.

## 0.15.0

- TCP и UDP через основной NaïveProxy HTTPS-туннель с VLESS внутри CONNECT, без дополнительного внешнего порта.
- Совместимость со старыми TCP-профилями и подсказка о необходимости обновить HTTPS на сервере через SSH.
- Отдельный тестовый UID проверяет TUN, 128 КиБ TCP и 100 UDP-пакетов размером 64–1300 байт. Производственная подпись пока недоступна.

## 0.14.0

- Отдельные режимы своего сервера HTTPS CONNECT и подписок. SSH закрепляет открытый ключ сервера и принимает пароль либо выбранный файл ключа.
- Встроенные NaïveProxy и Xray для ARM64 и x86-64, управление HTTPS, дополнительным REALITY и SOCKS5. Размер APK укладывается в лимит установленного загрузчика.
- Проверка подписанных обновлений при открытии каждого режима. Android-тест выполняет два запуска со свежей отметкой предыдущей проверки и открытие при уже выполняющемся запросе.

## 0.13.0

- Отдельный DNS для каждого сервиса; ручной выбор закреплён, автоматический резерв включается явно.
- Две неудачные проверки, паузы для кандидатов и переключение только новых соединений.
- Кеш выбранных маршрутов по сети, полный перебор вручную и экран результатов по сервисам.
- Подпись манифестов обновлений и DNS-каталога с проверкой срока действия.


## 0.11.0

- Telegram проверяет настоящий ответ MTProto до выбора маршрута. Добавлены
  ограниченный по времени поиск, прямые подключения к нужному дата-центру и
  запасные маршруты. Неотвечающий WebSocket больше не считается рабочим прокси.
- Проверка Telegram охватывает DC1–DC5; в интерфейсе видны число ответов и задержка.
  Проверка не прерывает активные подключения и не входит в аккаунт.
- В меню «Маршруты» появились независимые настройки зарубежного реле для
  нейросетей и запасного реле Telegram. Их можно отключить для прямого подключения.
  Нейросети и Instagram включены по умолчанию при новой установке.
- Исправлена маршрутизация DNS для выбранных сервисов. Прямые исключения
  сохраняют приоритет; недоступный DNS получает ограниченный срок ожидания.
- Автоматический подбор продолжает поиск после быстрых стратегий и сохраняет
  рабочие методы YouTube и Discord отдельно. Смена сети и отказ сохранённого
  метода запускают новый подбор.
- Состояние ChatGPT отличает ответ публичной страницы от регионального отказа,
  проверки браузера и ошибки соединения. Частичные результаты больше не
  подписываются как полный успех или обязательно как отсутствие рабочего DPI.
- Адрес реле ChatGPT выбирается по отдельному проверенному HTTPS-ответу API
  входа; выбор применяется к новым соединениям без повтора пользовательских запросов.
- QUIC переключается на TCP с сохранением UDP-пакетов RTP, STUN, DTLS и TURN.
- Отладочный APK **SorryRKN Test** устанавливается отдельно как
  `dev.graybridge.dev`; release сохраняет `dev.graybridge` и требует подписи
  владельца ключа перед установкой в качестве обновления.

Проверки протоколов и публичных адресов не подтверждают вход в пользовательский
аккаунт, загрузку всех медиа или работу голоса Discord. Конкретные результаты
сборки и испытаний должны оцениваться отдельно от этого списка изменений.
