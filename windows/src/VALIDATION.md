# Проверки Windows 1.4.0

Исходники включают маршруты DNS по сервисам, явный автоматический резерв, кеш проверок по сети, проверку подписанных данных и резервирование настроек.

- Go-тесты и vet прошли; проверяются отдельные рабочие DNS, приоритет прямых исключений, закрепление ручного выбора, две ошибки перед переключением, cooldown, срок кеша и подписи, изменение payload/ключа, ограничение TTL клиентских ответов и восстановление настроек без смены секрета.
- GitHub Actions собирает Setup и ZIP из исходников, запускает Go и 11 тестов встроенного Python runtime. Отдельная изолированная Windows-машина проверяет WinDivert, DNS-перехват, запуск/остановку winws, GUI, восемь списков маршрутов, сохранение настроек и секрета, установку и удаление.
- Экспорт/восстановление ключа данных проверяются на временных ключах: тот же открытый ключ после восстановления и отказ при неправильном пароле. Ключ выпуска в этих тестах не используется.
- Живое сравнение семи профилей и восьми сервисов выполняется отдельно без драйвера. Это публичные HTTPS-ответы; аккаунты, генерация, воспроизведение видео, звонки и все операторы не подтверждены.

Установщик/UAC/WinDivert на компьютере владельца не запускались. Нативные проверки выполняются только в явно выделенной изолированной машине; `windows/validate.ps1` требует `-IsolatedTestMachine`.

Окончательные ссылки на CI, контрольные суммы пакетов и публичный канал обновлений публикуются в отчёте релиза. Исторические результаты Windows 1.2.0 доступны в Git-теге `windows-v1.2.0` и не считаются повторной проверкой этой версии.
