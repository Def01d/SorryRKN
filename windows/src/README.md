# SorryRKN для Windows 1.4.0

Windows 10/11 x64. Установщик и переносной ZIP содержат zapret/winws, WinDivert и встроенный Telegram runtime; установка Python не нужна.

## Начало работы

Установите Setup.exe или распакуйте ZIP целиком. Запустите SorryRKN, подтвердите системный запрос прав администратора, выберите сервисы и нажмите большую кнопку. Закрытие окна сворачивает программу в трей; «Выход» завершает собственные сетевые процессы.

Для Telegram включите соединение и нажмите «Подключить Telegram». Локальный прокси слушает только `127.0.0.1:1443`. Секрет генерируется один раз и защищён Windows DPAPI текущего пользователя.

## DNS и маршруты сервисов

Откройте **«··· → DNS и нейросети»**. Общий DNS используется по умолчанию. Кнопка **«Маршруты»** позволяет выбрать DNS отдельно для ChatGPT, Claude, Gemini, Grok, Copilot, DeepSeek, Perplexity и NotebookLM:

- «По умолчанию» — общий профиль.
- Конкретный профиль — закреплённый ручной выбор.
- «Авто с резервом» — разрешение переключать DNS этого сервиса после двух неудачных анонимных проверок. Challenge и HTTP 429 не вызывают смену выхода. За цикл пробуется один запасной вариант; неудачные кандидаты получают паузу.

Настройки применяются после переподключения. При автоматическом восстановлении меняются ответы DNS для новых соединений, пользовательские запросы не повторяются, открытые сокеты не переносятся. Клиенту может потребоваться закрыть старое соединение. Доменные группы включают адреса API и ресурсов; общие вспомогательные домены используют общий профиль.

По умолчанию экран показывает сервисы и настроенный/действующий профиль. «Вся матрица DNS» открывает подробное сравнение. При запуске проверяются выбранные маршруты, успешные результаты кешируются по сети и настройкам на 30 минут; неполные/неудачные быстрые проверки — на 2 минуты. «Проверить» запускает полный перебор вручную. Для подтверждения доступа требуется проверка в вашей сети: публичная страница, вход, генерация, голос и видео — разные сценарии.

Браузер должен использовать системный DNS. Собственный защищённый DNS браузера может обходить профиль приложения. Доступность внешних реле и географические ограничения определяются провайдерами и сервисами. Приложение не гарантирует зарубежный выход для произвольного сайта.

## Мои ресурсы

В меню «Мои ресурсы» добавляйте домены маршрута нейросетей и прямые исключения. Исключения имеют приоритет. Профили действуют для включённых нейросетей и явно добавленных доменов; выключенный сервис не считается подключённым через реле. Настройки не заменяются обновлениями списков.

## Обновление и сохранение настроек

Обычный [релиз Windows 1.4.0](https://github.com/Def01d/SorryRKN/releases/tag/windows-v1.4.0) содержит Setup.exe и ZIP. Встроенное обновление использует установщик, сверяет цифровую подпись манифеста, размер, SHA-256 и заголовок EXE. Старые установленные версии принимают совместимые плоские поля нового манифеста. Новая версия предлагается при очередной проверке; пункт «Обновить приложение» проверяет сразу. Установка требует подтверждения пользователя.

Перед ручным обновлением выйдите через трей. Установщик сохраняет настройки в `%LOCALAPPDATA%/SorryRKN`. Переносную версию обновляйте всем ZIP.

С первой записи настроек создаётся `config.json.bak`, включая защищённый секрет и выбранные маршруты. Повреждённый основной файл восстанавливается из читаемой копии. Если оба файла повреждены, программа останавливается с объяснением и сохраняет их для восстановления вместо генерации нового секрета.

Каталог DNS и манифест приложения проверяются закреплённым открытым ключом и сроком действия. При ошибке каталога сохраняются встроенные профили. Подпись данных не является подписью Windows EXE и не заменяет сертификат APK Android.

Сборка исходников: [BUILD.md](BUILD.md). Проверки: [VALIDATION.md](VALIDATION.md). В пакет включены лицензии сторонних компонентов.
