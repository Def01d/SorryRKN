# SorryRKN для Windows

Windows 10/11 x64. Исходники 1.2.0: оригинальный zapret/winws + WinDivert и Telegram-прокси на основе Flowseal; установка Python не нужна. Интерфейс выполнен в чёрно-бело-серых тонах.

Установите Setup.exe и откройте SorryRKN. Windows запросит права администратора для WinDivert. Включите нужные переключатели и нажмите большую кнопку. Закрытие окна сворачивает приложение в системный трей; правый клик по значку позволяет включить, выключить и полностью выйти. «Выход» закрывает собственные сетевые процессы; чужие программы приложение не останавливает.

Для Telegram включите соединение, нажмите «Подключить Telegram» и подтвердите добавление прокси. Он слушает только 127.0.0.1:1443. Секрет генерируется один раз и хранится зашифрованным через Windows DPAPI под текущим пользователем; ссылка открывается только по вашему нажатию и не попадает в командную строку процесса.

В версии 1.1 откройте «Мои ресурсы» в меню ··· или трея. В «Через DNS-профиль» добавьте домены нужных сервисов, в «Напрямую» — исключения. Можно вставлять HTTP/HTTPS-ссылки, по одной в строке; сохраняется домен с поддоменами. Максимум 256 записей в каждом списке. Исключение имеет приоритет над пользовательским DNS-профилем, встроенными нейросетями и DPI. Изменения применяются при следующем включении; после смены правил перезапустите браузер или проверяемое приложение. Пользовательские DNS-домены активируются при запуске даже с выключенным переключателем встроенных нейросетей. Данные GitHub не заменяют эти списки. Удалите строку и сохраните, чтобы убрать правило.

DNS-профиль использует Comss и помогает только для маршрутов, поддерживаемых провайдером. Он не предоставляет зарубежный IP для произвольного сайта. Доменные исключения DPI работают для HTTP/TLS и распознаваемого QUIC; протокол без видимого домена или собственный защищённый DNS/ECH может не позволить распознать ресурс. У сервиса могут быть отдельные домены API и CDN — при необходимости добавьте и их.

Автоподбор начинает с сохранённого успешного метода и первых 6 профилей. Если ни один не прошёл все проверки, автоматически проверяется оставшийся каталог. Для Discord проверяются API, PNG с CDN и настоящий WebSocket Hello; для YouTube требуется HTTP 204 от контрольного адреса. Это проверка доступности, а не воспроизведения видео или голосового звонка. При частичном результате приложение показывает «Частичный доступ». Ручной метод можно выбрать нажатием строки «Обход DPI» при выключенном соединении.

Telegram 1.2.0 проверяет маршруты собственным запросом MTProto до передачи пользовательских данных. Используются TCP 443/5222/80, официальный WSS и ограниченный резерв через существующий пул CF. Неработающий маршрут не задерживает все остальные на минуты. H2 `/api`, возвращавший 404 в диагностике, исключён из активного пути. Переписка не повторяется через альтернативные соединения; после обрыва клиент Telegram переподключается сам. Фоновая проверка всех пяти дата-центров обновляет статус и задержку каждые 30 секунд. Открытый локальный порт больше не выдаётся за подтверждённый доступ.

Профиль «Нейросети и Instagram» использует Comss DNS с несколькими резервными адресами для известных доменов ChatGPT, Claude и Gemini и правила TCP/QUIC DPI для Instagram. Для доменов YouTube, Discord, Telegram и Instagram добавлен обычный защищённый DNS Cloudflare/Google с резервированием. Он исправляет подмену/отказ DNS, но не меняет внешний IP. Прямые исключения имеют приоритет. Системный UDP DNS перехватывается на лету; настройки адаптеров и hosts-файл не изменяются. Собственный защищённый DNS браузера и DNS через TCP могут обходить перехват; при необходимости выберите системный DNS в браузере. Comss не предоставляет зарубежный IP всем программам и не снимает ограничения аккаунта.

ChatGPT и Instagram проверяются при подключении и раз в минуту. Региональный отказ и требование браузерной проверки не считаются успехом. Если требуется проверка браузера, откройте ChatGPT вручную: автоматический HTTP-тест не заменяет пользовательскую сессию. Для полной блокировки адресов или регионального отказа нужен доступный внешний VPN/прокси; локальный обход не гарантирует работу во всех сетях.

`check-network.exe -output network-check.json` выполняет проверки HTTPS/API/WebSocket без прав администратора и сравнивает системный DNS с защищённым. Он не меняет настройки компьютера и не включает DPI. Протокольная проверка Telegram для разработчика: `runtime\python\python.exe scripts\check-telegram.py --output dist\telegram-check.json` из каталога исходников. [Результаты и границы проверки](VALIDATION.md).

Совместимые параметры стратегий, текстовые списки, небольшие fake-пакеты .bin и Telegram-домены обновляются с GitHub; CMD/BAT и Python-код из обновлений не выполняются. Данные сохраняются отдельными снимками и применяются при следующем включении. Новые бинарные алгоритмы движка требуют обновления программы. Новые версии предлагаются при запуске; установщик скачивается после подтверждения и проверяется по размеру и SHA-256. Windows-сборка не подписана сертификатом издателя.

Настройки, ограниченные по размеру журналы и диагностика: `%LOCALAPPDATA%\SorryRKN`. Меню «Диагностика» создаёт JSON без секрета Telegram. Перенос программы другому пользователю сохраняет программу, но его настройки/секрет создаются отдельно.

Поддерживаемые CPU: Intel/AMD x64. WinDivert перехватывает TCP/UDP на компьютере; фактический обход зависит от сети. Не запускайте одновременно другие программы на основе zapret/WinDivert.
