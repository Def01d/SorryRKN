# Проверка Windows 1.0.0

Нативная проверка на Windows Server 2025 (10.0.26100, x64) успешно завершена.

- AES-CTR по вектору NIST через встроенные Python/cryptography; шифрование секрета DPAPI.
- Запуск и остановка оригинального winws/WinDivert, закрытие собственных дочерних процессов.
- Перехват DNS для AI-домена, ответ NODATA на AAAA, освобождение дескриптора драйвера.
- Запуск Telegram из интерфейса, работа после закрытия окна в трее, отключение и полный выход.
- Установка NSIS, проверка установленного EXE и встроенного Python, повторный нативный тест, удаление и сохранение настроек.
- 22 совместимых профиля; модульные проверки логики и гонок: go test -race ./internal/core.

Обход на сети конкретного оператора, доступ к аккаунтам нейросетей и скорость Telegram в этой среде не проверены.
