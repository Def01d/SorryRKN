# Проверка Windows 1.1.0

**Исторический отчёт Windows 1.1.0.** Результаты ниже не являются проверками Windows 1.2.0: в частности, прежний успешный запуск WinDivert не подтверждает полный драйверный путь новой версии. [Текущие проверки Windows 1.2.0](src/VALIDATION.md) · [Установка текущей версии](../docs/WINDOWS.md).

Нативная проверка на Windows Server 2025 (10.0.26100, x64) успешно завершена.

- AES-CTR по вектору NIST, шифрование секрета DPAPI, встроенный Telegram-прокси и освобождение его порта.
- Оригинальный winws/WinDivert: запуск, остановка, закрытие собственных процессов и освобождение драйвера.
- Реальный запуск профиля прямого соединения первым, без DPI-desync, перед остальными методами.
- Редактор «Мои ресурсы»: открытие из интерфейса, нормализация URL/wildcard, сохранение личных настроек.
- Запуск только пользовательского DNS-профиля при выключенных встроенных сервисах; реальный перехват UDP DNS AAAA пользовательского домена и ответ NODATA.
- Системный трей, включение/выключение и полный выход; установка NSIS, проверка установленного EXE и Python, повторный нативный тест, удаление с сохранением настроек.
- go test -race ./internal/core: успешно. Проверены приоритет прямых правил, IDN, опасный ввод, лимиты, обновление снимков без потери настроек и общий список исключений для двух наборов по 256 доменов.

CI: https://github.com/Def01d/SorryRKN/actions/runs/37273868738

Доступ на сети конкретного оператора, региональные ограничения аккаунтов и скорость Telegram в этой среде не проверены.
