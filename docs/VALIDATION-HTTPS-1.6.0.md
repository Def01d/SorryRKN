# Проверки HTTPS TCP/UDP, Windows 1.6.0 и исходников Android 0.15.0

Основной режим передаёт TCP и UDP через VLESS внутри NaïveProxy HTTPS CONNECT. Внешний порт сервера — TCP 443. Это сочетание существующих протоколов. Дополнительный VLESS listener и SOCKS-шлюз доступны только на loopback VPS.

Проверки Windows выполнялись в GitHub Actions на изолированных машинах. Использовались производственные конфигурации TUN для HTTPS, HTTPS с TCP/UDP и VLESS. Проверены HTTPS, WebSocket Hello, 100 UDP-пакетов размером 64, 160, 1000 и 1300 байт, установка, удаление, сохранение настроек и повторные проверки обновлений. Тест завершения движка проверяет штатный код выхода. Сигналер игнорирует собственный Ctrl+Break, а программа ждёт завершения движка перед принудительным закрытием.

На Ubuntu проверена миграция настоящей серверной части 1.5.0. Новый профиль сохраняет прежние HTTPS-пароль и сертификат, добавляя возможность передачи датаграмм. Проверки охватывают настоящий Caddy, правильную/неправильную аутентификацию, страницу сайта, повторную установку, закрытые службы, TCP и UDP, а также запрет обращения к специально поднятому частному сервису. Повтор серверной проверки потребовался после ошибок TLS публичного контрольного адреса и загрузки официального архива; ссылка на итоговый CI находится в отчёте публикации.

На Android 15 API 35 x86_64 отдельный UID передал 128 КиБ TCP и 100 UDP-пакетов через TUN, встроенные Xray и NaïveProxy, Chromium HTTPS CONNECT и Linux-сервер. Собраны ARM64 и x86_64, проверены APK CRC, 16-КиБ zipalign, лимит 64 МиБ и соответствие встроенных серверных скриптов Windows. Манифест исходников содержит 802 файла и проверен по Git-объектам. Итоговые размеры и SHA-256, а также пределы проверки находятся в android-validation.json в релизе.

Чаты Discord используют TCP/WebSocket. UDP/STUN подтверждает доставку датаграмм и не подтверждает успешный голосовой звонок. Анонимный Discord Hello не подтверждает вход в аккаунт или работу установленного клиента. Физический Android ARM64, все операторы и сравнение с ТСПУ не проверялись. UDP внутри TCP может задерживаться при потерях во внешнем соединении.

Для своего существующего VPS после обновления приложения нужно отключить VPN и повторить настройку HTTPS через SSH. Старые сохранённые профили остаются TCP-only. На каждом устройстве требуется получить новый профиль.

Производственный Android канал остаётся на подписанной 0.11.0. Прежний ключ Android недоступен, поэтому тестовый или неподписанный APK в основной канал не публикуется. Установщик, UAC и WinDivert на компьютере владельца для этих проверок не запускались.
