# DNS и нейросети

В Windows 1.4.0 и исходниках Android 0.13.0 добавлен экран **«··· → DNS и нейросети»**. Он сравнивает публичные HTTPS-ответы ChatGPT, Claude, Gemini, Grok, Copilot, DeepSeek, Perplexity и NotebookLM через каждый DNS-профиль. Windows доступен в обычном релизе и обновлении приложения. Android 0.13.0 ожидает прежнюю подпись и пока доступен только в исходниках.

## Маршруты сервисов

Кнопка «Маршруты» открывает отдельный выбор DNS для каждого сервиса. «По умолчанию» использует общий DNS, конкретный профиль закрепляет ручной выбор, «Авто с резервом» явно разрешает автоматическую смену.

Авто проверяет фиксированные публичные адреса без аккаунтов. После двух неудачных проверок пробуется один запасной профиль за цикл; неудачные кандидаты получают паузу. Challenge и HTTP 429 сохраняют текущий выход. Меняются только новые соединения; активные сокеты и пользовательские запросы не переносятся и не повторяются. Для DNS-ответов авто-маршрута ограничен срок клиентского кеша. Прямые исключения и режим своего IP важнее автоматического резерва.

При открытии приложения проверяются выбранные маршруты. Успешные результаты кешируются по сети и настройкам на 30 минут, неполные быстрые проверки — на 2 минуты. Кнопка «Проверить» запускает полный перебор вручную. По умолчанию видны сервисы и настроенный/действующий профиль; «Вся матрица DNS» показывает подробности. Результат старой сети помечается отдельно.

Список доменов сервисов общий для Android и Windows: [services.json](../services.json). Вспомогательные общие домены используют общий профиль. Сохранение настроек требует следующего подключения; собственный DNS браузера может обходить системные правила.

## Проверка и выбор

При запуске приложение выполняет проверку в фоне. Android ограничивает повторные автоматические проверки в одном процессе интервалом пять минут. В экране можно выключить автопроверку или запустить её вручную. Проверки ограничены по времени и числу одновременных соединений; открытие экрана не включает VPN, DPI или Telegram.

Результаты показывают дату, HTTP-статус и время запроса. «Страница доступна» означает успешный публичный HTTPS-ответ. «Вход не проверен» означает перенаправление или необходимость авторизации. «Проверка браузера», HTTP 403 и лимит запросов показаны отдельно. «Отказ по региону» выводится только при найденном явном региональном отказе. Запросы, которые не успели выполниться, остаются непроверенными. Это не проверка аккаунта, подписки или отправки сообщения.

Выберите профиль и нажмите **«Сохранить DNS»**. Он сохраняется между запусками и применяется при следующем включении соединения. Проверки не переключают выбранный профиль. Для обновившегося DNS браузеру может понадобиться закрыть прежние соединения; собственный DNS браузера может обходить профиль приложения.

В Android внешнее реле нейросетей должно быть включено в меню «Маршруты» для применения выбранного профиля. Режим со своим IP не использует реле для обычного трафика, автоматическое сравнение в нём приостановлено. Нажатие «Проверить» явно запускает отдельные диагностические запросы через все профили даже в этом режиме. Обычные сайты продолжают использовать обычный защищённый DNS, прямые исключения имеют приоритет.

## Обновление каталога

Каталог [dns-profiles.json](../dns-profiles.json) включён в приложение и может обновляться из основной ветки этого репозитория не чаще раза в сутки при включённых обновлениях данных GitHub. Неудачный или некорректный ответ сохраняет прежний каталог. Встроенные профили сохраняются при обновлении, поэтому выбранный профиль не исчезает, если его пропустили в новом списке. Новые профили добавляются в этот файл после проверки адресов по источнику провайдера.

Новые клиенты проверяют цифровую подпись каталога и срок действия перед кешированием. При ошибке остаются встроенные профили. Каталог содержит только имена, HTTPS-адреса и публичные bootstrap IP; исполняемый код из него не загружается. Проверка сертификата и имени HTTPS-сервера обязательна и для DNS, и для сервиса. Результаты проверок сохраняются на устройстве; cookies, аккаунты и сообщения в запросах не используются. Во время сравнений DNS-провайдеры получают запросы доменов восьми проверяемых сервисов.

Для разработчиков Windows: `check-network.exe -dns-matrix -output dns-matrix.json` выполняет такие же проверки без прав администратора и запуска драйвера. Это проверка доступности из сети компьютера, а не доказательство работы всех сценариев сервиса.
