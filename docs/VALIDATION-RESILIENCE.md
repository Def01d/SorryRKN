# Проверки Windows 1.4.0 и исходников Android 0.13.0

Проверки выполнены 25 октября 2026 года. Android production APK ожидает восстановления прежнего ключа; основной подписанный канал остаётся на 0.11.0.

## Код и данные

- Полный Python-набор: **429 тестов и 34 подтеста прошли** после сборки изолированных tpws/ByeDPI fixtures. Дополнительно тот же набор проходит в Linux CI.
- Go-тесты, vet и сборка Windows прошли. Новые проверки охватывают фактический выбор разных DNS, прямые исключения, отсутствие автоматических запросов к исключённому сервису, ручное закрепление, две ошибки перед резервом, паузу для кандидатов, TTL клиентских ответов и восстановление настроек без смены секрета.
- Подписанные данные проверены независимо .NET-подписывающим инструментом, Go, Python/cryptography и Android Java. Изменённые payload, подпись, неизвестный ключ, истёкший срок и подпись из будущего отклоняются. Старые внешние поля не заменяют проверенный payload.
- Экспорт и восстановление ключа данных проверены на временных ключах: исходная идентичность сохраняется, неправильный пароль отклоняется. Ключ выпуска в этих тестах не используется. Переносимую копию настоящего ключа владелец создаёт отдельно с собственным паролем.
- `check-network.exe -verify-data FILE.json` проверяет подпись и срок JSON без сети и драйвера. CI проверяет таким образом оба манифеста приложений и каталог DNS.

## Android

- Собраны debug, неподписанный release и instrumentation APK для ARM64 / x86_64, версия 0.13.0 / code 20.
- Android 15 / API 35 x86_64: каталог из APK, семь DNS-профилей, восемь списков маршрутов, сохранение ChatGPT=auto и Gemini=GeoHide EU, неизменность Telegram-секрета и вызов проверяющего модуля из Python в Java прошли. Настройки теста восстановлены; сам тест выбора не запускает VPN.
- Через настоящий локальный VPN в эмуляторе **7/7** фиксированных публичных проверок прошли: YouTube `generate_204`, Discord API, PNG CDN и WebSocket Hello, Instagram, публичная страница ChatGPT и OAuth providers. Проверка цепочки сертификата и имени сервера обязательна. В том же прогоне Telegram подтвердил MTProto-ответы **5/5 DC**.
- Фоновая проверка ChatGPT в соседнем по времени запросе получила challenge, хотя отдельный публичный прогон прошёл. Это подтверждает зависимость от клиента/маршрута/времени и необходимость показывать отдельные результаты, а не постоянный рейтинг доступности.

## Windows и публикация

GitHub Actions собирает Setup и ZIP, выполняет Go/vet/11 Python-тестов встроенного Telegram runtime. Отдельная изолированная Windows-машина проверяет WinDivert, DNS-перехват, запуск/остановку winws, GUI и редактор восьми маршрутов, сохранение секрета, установку с сохранением настроек и удаление. Установщик/UAC/WinDivert на компьютере владельца не запускались.

Живое сравнение **7 × 8 = 56** сочетаний на Windows без драйвера завершено: 12 публичных доступных ответов, 11 ответов с непроверенным входом, 13 challenge, 6 HTTP 403, 8 ошибок DNS и 6 тайм-аутов. Ни один профиль не обеспечивает все сценарии сервиса. Это снимок одной доступной сети, а не встроенный рейтинг.

Окончательные ссылки CI и контрольные суммы публикуются с обычным релизом. После публикации точных файлов по тегу канал обновлений активируется отдельно и проверяется публичным загрузчиком.

## Границы результата

Вход в аккаунты, генерация сообщений, воспроизведение видео, скачивание пользовательских медиа и голосовые звонки не проверены. Физические ARM64-телефоны, измерения батареи и все операторы не проверены. Автоматический резерв использует публичные проверки и меняет только будущие DNS-ответы; клиентский DNS-кеш и уже открытые соединения могут сохранять прежний маршрут. Свой зарубежный сервер не использовался по выбору владельца.
