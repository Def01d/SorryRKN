# SorryRKN на Windows

[← Главная](../README.md) · [Android](ANDROID.md) · [Помощь](FAQ.md)

## Скачать

[**Установщик 1.1.0**](https://raw.githubusercontent.com/Def01d/SorryRKN/windows-v1.1.0/windows/SorryRKN-Windows-1.1.0-Setup.exe) · [**Переносной ZIP 1.1.0**](https://raw.githubusercontent.com/Def01d/SorryRKN/windows-v1.1.0/windows/SorryRKN-Windows-1.1.0.zip)

Требования: Windows 10/11 x64, Intel/AMD, права администратора для WinDivert. ARM64 и 32-битная Windows этой сборкой не поддерживаются. Python и сетевые компоненты включены в пакет.

## Установка

1. Запустите установщик и подтвердите запрос администратора.
2. Выберите папку установки и дождитесь завершения.
3. Откройте SorryRKN через ярлык.

**Переносная версия:** распакуйте ZIP целиком в отдельную папку и запустите `SorryRKN.exe`. Папки `runtime` и `licenses` должны оставаться рядом с EXE; один файл EXE не является полной программой.

Сборка пока не подписана сертификатом издателя, поэтому Windows может показывать «Неизвестный издатель» или сообщение SmartScreen. Если файл вызывает сомнения, сравните его SHA-256 с [опубликованной суммой](../windows/SHA256SUMS.txt). Отключать защиту Windows для установки не требуется.

## Первое включение

1. Закройте другие запущенные программы на основе zapret/winws.
2. Откройте SorryRKN и подтвердите запрос прав администратора.
3. Включите нужные переключатели и нажмите большую круглую кнопку.
4. Дождитесь подбора, затем проверьте сервис в приложении или браузере.

Повторное нажатие выключает соединение или отменяет подбор. Изменение сервисов и ручного профиля выполняется при выключенном соединении.

## Telegram

Включите **«Telegram»**, запустите соединение, затем нажмите **«Подключить Telegram»**. Telegram Desktop должен быть установлен; подтвердите в нём добавление прокси.

Прокси слушает только `127.0.0.1:1443` на этом компьютере. Подключить к этому адресу телефон нельзя. Секрет генерируется один раз и хранится с защитой Windows DPAPI для текущего пользователя.

После выключения SorryRKN выключите этот прокси в настройках Telegram, если хотите использовать прямое соединение.

## Трей и работа в фоне

Закрытие окна кнопкой **×** сворачивает приложение в системный трей. При необходимости раскройте скрытые значки рядом с часами.

Правый клик по значку SorryRKN открывает меню:

- **«Открыть SorryRKN»** — вернуть окно.
- **«Включить» / «Выключить»** — управлять соединением.
- **«Выход»** — выключить соединения и завершить приложение.

SorryRKN закрывает свои дочерние процессы. Настройки сетевых адаптеров и файл hosts не изменяются. Автоматический запуск при входе в Windows в версии 1.1.0 не настроен.

## Автоматический и ручной подбор

Быстрый автоподбор начинает с сохранённого успешного метода и проверяет до шести основных профилей. **`··· → Расширенный подбор`** проверяет весь совместимый каталог — 22 профиля в версии 1.1.0.

Для ручного выбора выключите соединение, нажмите текст строки **«Обход DPI»** и выберите профиль. После смены сети можно использовать **«Подобрать заново»**.

**«Частичный доступ»** означает, что часть проверок не прошла. При полном провале автоматического подбора DPI отключается; выбранные Telegram и DNS-профиль могут продолжать работать. Проверяются HTTPS YouTube, Discord API, CDN и WebSocket Hello; реальные видеопотоки и голос нужно проверить отдельно.

## Нейросети и Instagram

Включите **«Нейросети и Instagram»** перед запуском. Для известных доменов ChatGPT, Claude и Gemini используется выборочный Comss DNS, для Instagram — отдельное правило DPI.

Если браузер использует собственный защищённый DNS, профиль может не примениться. Проверьте настройку DNS в браузере и при необходимости выберите системный DNS, затем перезапустите браузер. Профиль не снимает ограничения аккаунта и не предоставляет зарубежный IP всем приложениям.

## Мои ресурсы

Откройте **`··· → Мои ресурсы`** или одноимённый пункт в трее. Добавьте домены для DNS-профиля и прямые исключения, сохраните и выключите/включите соединение. Исключения имеют приоритет над DNS-профилем и DPI. Пользовательские списки хранятся в настройках и не заменяются данными GitHub.

[Примеры, приоритеты и ограничения →](USER-RULES.md)

## Обновления

Новые версии проверяются при запуске; вручную — **`··· → Обновить приложение`**. Установщик скачивается после подтверждения и проверяется по размеру и SHA-256. Перед установкой программа останавливает свои соединения и завершает работу.

Данные: **`··· → Обновить данные GitHub`**. Автопроверка включается пунктом **«Обновлять данные автоматически»**. Новые данные применяются при следующем включении. Обновляются безопасно разобранные параметры, текстовые списки, небольшие fake-пакеты и Telegram-домены; скачанные BAT/CMD и Python-код не выполняются. Новые бинарные алгоритмы требуют новой версии программы.

Для ручного обновления сначала выберите **«Выход»** в трее, затем запустите новый установщик. В переносной версии замените файлы только после полного выхода.

## Настройки, диагностика и удаление

Настройки, журналы и JSON-диагностика находятся в `%LOCALAPPDATA%\SorryRKN`. Откройте **`··· → Диагностика`**, чтобы создать отчёт. Штатный отчёт не содержит секрета Telegram.

Удаление установленной версии: завершите программу через трей, затем откройте **Параметры Windows → Приложения → SorryRKN → Удалить**. Пользовательские настройки сохраняются для переустановки. Для полного удаления после выхода и деинсталляции можно удалить папку `%LOCALAPPDATA%\SorryRKN`; это также сбросит секрет локального прокси.
