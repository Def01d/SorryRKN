# Свой VPN и подписки

В Windows нажмите название режима над кнопкой подключения и выберите **«VPN и подписки»**. Сначала отключите текущее соединение. Большая кнопка запускает или останавливает выбранный туннель, а «Выход» в трее завершает его. Закрытие обычного окна оставляет соединение в трее.

## Подключить свой Linux-сервер

1. Для основного HTTPS-режима подготовьте сервер x86-64 под Debian или Ubuntu с systemd и доступом по SSH. Нужен root либо пользователь с sudo без запроса пароля. Разрешите входящий TCP 443 в панели хостинга. Порт должен быть свободен. Если используете доменное имя и публичный сертификат, имя должно вести на этот сервер.
2. Откройте **«Свой сервер»**. Введите адрес, порт SSH, имя пользователя и пароль либо путь к закрытому ключу. Для защищённого ключа в поле пароля введите парольную фразу.
3. Выберите **«Установить HTTPS и добавить узел»**. При первом соединении сверьте отпечаток SSH с консолью хостинга. После подтверждения программа запомнит его для этой пары адреса и порта. При смене ключа сначала проверьте новый отпечаток, затем используйте **«Забыть ключ сервера»**.
   Для проверки отпечатка SSH в консоли хостинга можно выполнить `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256`. Если сервер предъявил другой тип ключа, сверьте соответствующий публичный файл.

4. После установки закройте окно сервера и включите VPN большой кнопкой. При настройке с другого устройства оно получит собственные данные доступа. Через меню сервера можно проверить состояние службы, запустить или остановить её. Главная кнопка управляет подключением текущего устройства.

Основной транспорт использует HTTPS CONNECT и стек Chromium в NaïveProxy. Посетитель без данных доступа получает обычный ответ сайта. При настройке по IP клиент получает доверенный сертификат через уже проверенный SSH-канал. Такой сертификат привязан к вашему серверу, но публичный браузер может показать предупреждение. При настройке по публичному доменному имени Caddy запрашивает сертификат через ACME. Обычную страницу сайта можно заменить в `/usr/local/lib/sorryrkn-https/site/index.html`. Повторная настройка сохраняет содержимое страницы.

## Резервный маршрут

Для приложений, которым нужен UDP, или сети, где основной HTTPS-маршрут недоступен, откройте **«Свой сервер → Установить резервный TCP · REALITY»**. Для него требуется свободный входящий TCP 8443, доступ VPS к GitHub и исходящее TLS-соединение к сайту для REALITY. Появится второй узел того же сервера. Основной HTTPS-транспорт передаёт TCP. Резервный использует VLESS с REALITY.

Кнопка **«Проверить»** в окне узлов выполняет короткий публичный запрос HTTPS через выбранный профиль. Если для своего VPS настроены оба маршрута, программа проверяет оба и показывает результаты рядом. Выбор подключения остаётся за вами.

## SOCKS5

Выберите **«Включить SOCKS5 через SSH»**. Программа запускает защищённую паролем службу на сервере и открывает локальный SSH-туннель. В поле результата появится SOCKS5-адрес на `127.0.0.1` с портом и данными доступа. Укажите его в приложении, которому требуется прокси. Эта функция работает независимо от подключения VPN. На сервере SSH должно быть разрешено перенаправление TCP (`AllowTcpForwarding`). Держите SorryRKN открытым в трее. После нового запуска снова включите SOCKS5, чтобы получить текущий локальный порт. В том же меню можно остановить службу на сервере.

## Подписки и узлы

Вставьте ссылку HTTPS от провайдера в **«Подписки и узлы»** и нажмите **«Добавить»**. Программа принимает текстовые и Base64-списки ссылок. Можно вставить ссылку одного узла. Выберите источник и узел, нажмите **«Выбрать узел»** и подключитесь на главном экране. **«Обновить»** заново загружает выбранную подписку. Если загрузка не удалась, ранее загруженные узлы доступны как прежде. **«Удалить»** удаляет источник с этого устройства.

Windows поддерживает распространённые варианты VLESS, VMess, Trojan, Shadowsocks и Hysteria2. Поддержка зависит также от транспорта и параметров ссылки. При частичном импорте программа сообщает, сколько записей пропущено. Профили и ссылки подписок на Windows хранятся в зашифрованной библиотеке DPAPI текущего пользователя.

## Обновления

Windows 1.5.0 проверяет подписанный манифест при каждом запуске. Если доступна более новая версия, появляется предложение скачать и установить её. Повторить проверку можно в меню **«Обновить приложение»**. Для перехода с 1.4.0 сразу воспользуйтесь этим пунктом. В самой версии 1.4.0 автоматические проверки ещё используют интервал в шесть часов.
