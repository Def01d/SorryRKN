# Свой VPN и подписки

В Windows нажмите название режима над кнопкой подключения и выберите **«VPN и подписки»**. Сначала отключите текущее соединение. Большая кнопка запускает или останавливает выбранный туннель, а «Выход» в трее завершает его. Закрытие обычного окна оставляет соединение в трее.

## Подключить свой Linux-сервер

1. Подготовьте VPS с Debian или Ubuntu, systemd и доступом по SSH. Нужен пользователь root либо пользователь с sudo без запроса пароля. Для WireGuard разрешите входящий UDP на порт 51823 в панели хостинга. Для резервного режима TCP нужен свободный порт 443.
2. Откройте **«Свой сервер»**. Введите адрес, порт SSH и имя пользователя. Используйте пароль SSH или путь к закрытому ключу. Если ключ защищён, в поле пароля укажите его парольную фразу.
3. Выберите действие установки и нажмите **«Выполнить»**. При первом соединении сверьте показанный отпечаток ключа SSH с отпечатком в консоли хостинга. После подтверждения программа запомнит его для этой пары адреса и порта. Отпечатки можно посмотреть в консоли VPS с помощью `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256` (укажите публичный файл того типа ключа, который показывает сервер). При смене ключа сначала проверьте новый отпечаток и воспользуйтесь кнопкой **«Забыть ключ сервера»**.
4. После установки профиль появится в **«Подписки и узлы»**. Закройте окно сервера и нажмите большую кнопку. Для другого устройства повторите установку с него, чтобы оно получило отдельные данные клиента.

Установка WireGuard создаёт интерфейс `srkn0`, отдельную службу systemd, включает перенаправление IPv4 и добавляет правила для трафика туннеля. Повторная установка для того же устройства сохраняет его ключ. Через список действий можно проверить состояние служб, остановить или снова запустить VPN на сервере. Кнопка на главном экране управляет только подключением текущего устройства.

## Если WireGuard не соединяется

В **«Свой сервер»** выберите **«Установить TCP · VLESS REALITY»**. Для этого режима серверу нужны свободный входящий TCP 443, доступ к GitHub для скачивания движка и исходящее TLS-соединение к сайту, используемому REALITY. После установки в «Подписки и узлы» появится отдельный узел. Можно выбрать его, если UDP недоступен в вашей сети. Состояние и остановка TCP доступны в том же меню.

## SOCKS5

На настроенном сервере WireGuard выберите **«Включить SOCKS5 внутри VPN»**. Поле результата покажет адрес, порт, логин и пароль. Подключите WireGuard и укажите их в настройках приложения, которому требуется прокси. Служба слушает TCP на приватном адресе VPN и требует пароль. Через то же меню её можно остановить.

## Подписки и узлы

Вставьте ссылку HTTPS от провайдера в **«Подписки и узлы»** и нажмите **«Добавить»**. Программа принимает текстовые и Base64-списки ссылок. Можно вставить ссылку одного узла. Выберите источник и узел, нажмите **«Выбрать узел»** и подключитесь на главном экране. **«Обновить»** заново загружает выбранную подписку. Если загрузка не удалась, ранее загруженные узлы доступны как прежде. **«Удалить»** удаляет источник с этого устройства.

Windows поддерживает распространённые варианты VLESS, VMess, Trojan, Shadowsocks и Hysteria2. Поддержка зависит также от транспорта и параметров ссылки. При частичном импорте программа сообщает, сколько записей пропущено. Профили и ссылки подписок на Windows хранятся в зашифрованной библиотеке DPAPI текущего пользователя.

## Обновления

Windows 1.5.0 проверяет подписанный манифест при каждом запуске. Если доступна более новая версия, появляется предложение скачать и установить её. Повторить проверку можно в меню **«Обновить приложение»**. Для перехода с 1.4.0 сразу воспользуйтесь этим пунктом. В самой версии 1.4.0 автоматические проверки ещё используют интервал в шесть часов.
