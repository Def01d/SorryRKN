# Проверки выбора DNS

Обычный релиз Windows 1.3.0 и подготовленный Android 0.12.0 (APK ожидает подпись прежним ключом). Это отчёт новой функции; предыдущие отчёты релизов 0.11.0 / 1.2.0 не считаются повторными сетевыми проверками этих сборок.

- Полный Android/Python набор: **421 тест и 34 подтеста прошли**. Первоначальный прогон без тестовых нативных бинарников завершился ошибками их отсутствия; после сборки этих fixtures штатным `scripts/test-network.sh` полный набор прошёл.
- Дополнительные проверки охватывают безопасный разбор каталога, сохранение встроенных профилей, передачу выбора в рабочий SmartDNS, режим своего IP, классификацию ответов, максимум восемь параллельных проверок, общий тайм-аут и отмену.
- Go: `go test ./...`, `go vet ./internal/core ./internal/platform` и сборка Windows GUI / `check-network` прошли. Покрыты выбор реального DNS-профиля, отдельный путь обычных доменов, классификация ответов и остановка параллельных проверок.
- Собраны Android debug, неподписанный release и instrumentation APK для ARM64 / x86_64. На Android 15 x86_64 инструментальная проверка прошла: каталог из APK доступен через Python loader, в списке семь профилей, выбор сохраняется, локальный Telegram-секрет не меняется, VPN не запускается.
- Выполнены живые сравнения **7 × 8 = 56** ячеек на Windows без запуска драйвера и из Android эмулятора. Ответы разных профилей различались: встречались доступные страницы, перенаправления на вход, Cloudflare challenge, HTTP 403, ошибки DNS и тайм-ауты. Ни один профиль не прошёл все сервисы.

Один Windows-прогон получил подтверждённый публичный API ChatGPT через Comss; несколько профилей ответили публичными страницами Gemini и Grok. При отдельном Android-прогоне ChatGPT выдавал challenge или сетевые ошибки, а некоторые другие сервисы отвечали. Это отражает зависимость от клиента, маршрута и времени. Эти результаты не должны становиться постоянным встроенным рейтингом DNS: приложение повторяет проверки в сети пользователя.

Результаты относятся к анонимным публичным запросам с проверкой TLS, без cookies и учётных данных. Аккаунты, генерация ответов, подписки, физические ARM64-телефоны и все операторы не проверены. Новый Windows GUI с повышением UAC и WinDivert на рабочем компьютере не запускался; управление Android проверено в эмуляторе. Смена выбранного DNS требует следующего включения соединения.

Повторение:

```powershell
cd windows/src
go test ./...
go vet ./internal/core ./internal/platform
go run ./cmd/check-network -dns-matrix -output dist/dns-matrix.json
```

```sh
cd android/src
bash scripts/test-network.sh
adb shell am instrument -w -e dnsProfilesChecks true dev.graybridge.dev.test/dev.graybridge.DeviceChecks
adb shell am instrument -w -e dnsMatrixLiveChecks true dev.graybridge.dev.test/dev.graybridge.DeviceChecks
```

Второй инструментальный сценарий сохраняет сравнение в `files/dns-matrix-live.json` тестового приложения. Код завершения COMPLETE означает завершение сравнения, а не доступность всех сервисов. Сводные результаты не содержат переписки, cookies или Telegram-секрета.
