# Проверки SorryRKN 0.9.2

- Python: 215 passed, 32 subtests passed. Новый тест использует настоящие локальные TCP/WebSocket: сервер передаёт бинарные данные, но не отвечает на клиентский ping. Соединение выдерживает простой и медленную передачу трёх медиа-пакетов, отвечает на серверный ping.
- В отдельном воспроизведении транспорт 0.9.1 на том же тестовом сервере принудительно закрывает рабочий канал (IncompleteReadError). Интервалы проверки сокращены для теста. Транспорт 0.9.2 проходит этот сценарий.
- Четыре восстановленных модуля Telegram (raw_websocket, bridge, pool, h2_transport) семантически совпадают с байткодом опубликованного APK 0.9.0.
- Android API 26 x86_64, эмулятор: ошибки фоновой проверки записываются в диагностику; в течение 23 секунд отсутствуют перезапуски движка, Telegram-слушатель остаётся доступен. Незавершённые исходящие Telegram-подключения в этом тесте заменены отменяемым ожиданием, поскольку внешние TCP-соединения стенда недоступны.
- Быстрый повторный запуск не ждёт тестовых проверок длительностью 5000 мс на метод. Отдельные методы Wi-Fi/мобильной сети сохраняются; изменение параметров метода отклоняет устаревший кеш. Принудительно остановленный движок автоматически восстанавливается.
- Проверки жизненного цикла: запуск/остановка tpws/ByeDPI + Telegram, Telegram-only при неудачном подборе, отмена подбора. Редактор пользовательских правил и сохранение настроек прошли проверку.
- Другой UID через настоящий TUN: TCP 128 KiB, UDP 1000 байт, восемь HTTPS-имён по 1 MiB, Discord WebSocket Hello, раздельные маршруты сервисов и DNS-профиль нейросетей.
- DNS: восстановление единственного Comss-провайдера после временного отказа; объединение 32 запросов, отмена отдельного клиента, корректные ID/TTL, отсутствие кеширования отказов. Сохраняется проверка сертификатов и TLS-имени.
- Gradle assembleDebug/assembleDebugAndroidTest/lintDebug: успешно; lint — 0 ошибок и 3 существующих предупреждения.
- APK: dev.graybridge, versionCode 11, minSdk 26, arm64-v8a + x86_64. Подписант прежний: 854ef7e3cbfdb5fc624bc3ec7b7d9e17780b709bac7fb85b77dbf4ea0acf2ef4. zipalign на 16 KiB прошёл.
