# Проверки SorryRKN 0.9.1

- Python: 219 passed, 32 subtests passed. Настоящие локальные TCP/WebSocket/HTTP2 соединения: здоровый канал переживает простой и медленную передачу фрагментированного кадра; молчащий канал закрывается; heartbeat-задачи освобождаются при остановке.
- DNS: восстановление единственного Comss-провайдера после временного отказа; 32 одновременных одинаковых запроса объединяются, отмена одного клиента не мешает остальным, ID ответов сохраняются, TTL уменьшается и истекает. Отказы DNS не кешируются. Проверка сертификатов и TLS-имени сохранена.
- Канал DNS-профиля, принявший TCP, но не ответивший на TLS ClientHello, закрывается по таймауту, его DNS-кеш сбрасывается. Relay освобождается при EOF сервера даже при открытом клиенте; действующий клиентский half-close сохраняет получение ответа.
- Gradle assembleDebug/assembleDebugAndroidTest/lintDebug: успешно; lint — 0 ошибок и 3 существующих предупреждения.
- Android API 26 x86_64, программный эмулятор: повторное включение с сохранёнными раздельными методами — 2989 мс при тестовых запросах по 5000 мс; первый холодный запуск с загрузкой Python/TLS — 11820 мс. Подбор не блокирует сохранённое подключение. Это измерения эмулятора, не Samsung.
- Принудительная остановка Python-движка: автоматическое восстановление соединения и Telegram-слушателя. Общая ревизия данных не удаляет рабочий метод; изменение параметров метода отклоняет устаревший кеш.
- Реальное отключение/включение мобильной сети эмулятора: соединение пересоздаётся в режимах только Telegram и ручного DPI, без ручного выключения приложения.
- Трафик другого UID через настоящий TUN: TCP 128 KiB, UDP 1000 байт, восемь HTTPS-имён по 1 MiB, Discord WebSocket Hello, раздельные маршруты YouTube/Discord/Instagram и DNS-профиль нейросетей.
- Редактор пользовательских ресурсов, приоритет прямых исключений и сохранение правил после обновления данных; запуск/остановка tpws/ByeDPI + Telegram, Telegram-only при неудачном подборе и отмена подбора — успешно.
- APK: dev.graybridge, versionCode 10, minSdk 26, arm64-v8a + x86_64. Подписант прежний: 854ef7e3cbfdb5fc624bc3ec7b7d9e17780b709bac7fb85b77dbf4ea0acf2ef4. Проверка zipalign на 16 KiB прошла.
