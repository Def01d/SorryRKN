# Проверки SorryRKN 0.9.3

- Python: 227 passed, 32 subtests passed; 12 новых проверок медиа-восстановления. Настоящие локальные TCP/WebSocket соединения: молчащий медиа-сервер, повторная загрузка видео через новое соединение, частично полученный и затем остановившийся кадр, медленный большой кадр, простой, клиентское backpressure и освобождение сокета после серверного Close.
- Раздельный сброс пула медиа конкретного DC сохраняет чат, другие DC и тестовые каналы; новая попытка пропускает неиспользуемые сокеты сбойной партии и может выбрать существующий резервный маршрут.
- HTTP2: пустые ответы на принятый медиа-запрос не оставляют native-сессию ждать бесконечно; медленная передача тела сохраняет соединение. Другая сессия на той же HTTP2 lane продолжает получать ответы. Сбойный маршрут исключается из новых попыток на короткое время, общий TCP не закрывается.
- Отдельное воспроизведение: транспорт 0.9.2 оставляет молчащий медиа-запрос ждать при живом TCP; 0.9.3 освобождает только эту сессию. Для локального сравнительного теста таймаут сокращён до 90 мс.
- Android API 26 x86_64, эмулятор: APK с реальным производственным таймаутом 60 секунд и нативным Android AES-CTR. Молчащий канал освобождён за 60.43 секунд, одновременно прошли 29 обменов работающего соседнего чата; повторное подключение передало 1048572 байт видео. Исходящий client PING отсутствует.
- Во время сценария исходная служба SorryRKN и Python-движок сохраняются, listener Telegram остаётся доступен, глобальных переподключений нет. Незавершённые внешние подключения прогрева заменены отменяемым ожиданием, поскольку внешние raw TCP стенда недоступны; сам тест медиа использует настоящие локальные сокеты и криптографию APK.
- Жизненный цикл: запуск/остановка tpws/ByeDPI + Telegram, Telegram-only при неудачном подборе, отмена подбора и освобождение портов. Редактор пользовательских правил: проверка ввода, нормализация, сохранение настроек и отдельный режим DNS-профиля.
- Проверки DNS, раздельного выбора методов и существующих транспортов входят в Python-набор. Java-логика запуска, фоновой проверки и VPN-маршрутизации в этом релизе не менялась.
- Gradle assembleDebug/assembleDebugAndroidTest/lintDebug: успешно; lint — 0 ошибок и 3 существующих предупреждения.
- APK: dev.graybridge, versionCode 12, minSdk 26, arm64-v8a + x86_64. Подписант прежний: 854ef7e3cbfdb5fc624bc3ec7b7d9e17780b709bac7fb85b77dbf4ea0acf2ef4. zipalign на 16 KiB прошёл. Установка поверх 0.9.2 успешна.
